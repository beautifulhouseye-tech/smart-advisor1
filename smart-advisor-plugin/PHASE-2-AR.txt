Smart Advisor 5.0 — المرحلة الثانية: الموافقة والخصوصية
=====================================================

ما أضيف في هذه المرحلة:
- خدمة SA_Customer_Profile لإدارة موافقة العميل.
- واجهات REST للمستخدم المسجل فقط:
  GET    /wp-json/smart-advisor/v1/profile
  POST   /wp-json/smart-advisor/v1/profile/consent  (consent: true أو false)
  DELETE /wp-json/smart-advisor/v1/profile
- التحقق من جلسة WordPress وREST nonce قبل الوصول إلى الملف.
- لا يتم إنشاء سجل عميل عند التسجيل؛ لا ينشأ إلا بعد موافقة صريحة.
- عند سحب الموافقة تُحذف بيانات البحث والمقاسات والتفضيلات وملخصات المحادثات المرتبطة بالحساب.
- دعم أدوات الخصوصية في WordPress لتصدير بيانات موافقة Smart Advisor وحذف بيانات الإضافة.
- حذف بيانات Smart Advisor عند حذف حساب WordPress.

حدود المرحلة:
- لم تُضف بعد واجهة الموافقة داخل صفحة حساب WooCommerce.
- لم تُفعّل بعد عمليات حفظ/استرجاع المقاسات والتفضيلات والذاكرة؛ لا يُفترض أن هذه البيانات تُجمع حالياً.
- لا تُدمج بيانات الزوار مع حساب المستخدم عند التسجيل.
- يجب اختبار REST عملياً على نسخة WordPress/WooCommerce تجريبية قبل الإنتاج.

اختبارات التنفيذ:
- فحص صياغة PHP لجميع ملفات الإضافة.
