Smart Advisor 5.0 — المرحلة الرابعة
واجهة الملف الشخصي داخل حساب WooCommerce

ما تم:
1. إضافة نقطة نهاية لحساب العميل باسم smart-advisor-profile.
2. إضافة رابط «مستشاري الشخصي» إلى قائمة حساب WooCommerce.
3. إنشاء واجهة عربية متجاوبة تعرض حالة الموافقة والخصوصية.
4. تمكين العميل من تفعيل حفظ تفضيلاته أو سحب الموافقة.
5. إضافة نموذج لإدارة الميزانية والعملة والفئات والألوان والتصاميم والخامات والعلامات التجارية واهتمامات التسوق والهدايا والمنتجات غير المرغوبة.
6. إضافة إدارة المشاريع المستقبلية: التأثيث، الزواج، البناء، الترميم، الهدايا، الإلكترونيات وغيرها.
7. عرض توصيات منتجات WooCommerce المنشورة والمتوفرة وفق التفضيلات المؤكدة.
8. جميع الطلبات تستخدم REST API مع WordPress REST Nonce، وتبقى عمليات القراءة والكتابة محمية بتسجيل الدخول والموافقة.

الفحوص المنفذة:
- PHP lint لجميع ملفات PHP: ناجح.
- Node syntax check لسكريبت واجهة الملف الشخصي: ناجح.
- فحوص وجود مسارات API وربط نقطة نهاية الحساب: ناجحة.
- فحص سلامة ZIP: ناجح.

ملاحظات قبل الإنتاج:
- يجب تثبيت الإضافة على نسخة تجريبية من WordPress مع WooCommerce واختبار صفحة «حسابي» فعلياً.
- عند تفعيل الإضافة تُسجل نقطة النهاية وتُحدّث قواعد الروابط الدائمة تلقائياً. إذا ظهر 404 بعد التحديث، احفظ صفحة الإعدادات > الروابط الدائمة مرة واحدة.
- التوصيات الحالية مطابقة أولية حسب الفئة والسعر، وليست نموذج ترتيب تعلم آلي.
- لا توجد رسائل تسويقية أو تنبيهات خارجية في هذه المرحلة.


إصلاح إضافي 5.0.1: تسجيل endpoint ضمن خريطة WooCommerce عبر woocommerce_get_query_vars، مع تحديث قواعد Rewrite مرة واحدة تلقائياً بعد التحديث.
