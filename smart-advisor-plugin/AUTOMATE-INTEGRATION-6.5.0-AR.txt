عقد التكامل بين AutoMate AI وSmart Advisor — الإصدار 6.5.1

المبدأ
- AutoMate AI هو المالك الوحيد لسياق المحادثة الحي، وسجل الرسائل، وتحديد النية، وصياغة الرد النهائي، وتنفيذ الإرسال.
- Smart Advisor هو مصدر بيانات WooCommerce وحقائق المتجر وذاكرة العميل الدائمة.
- لا ترسل سجل المحادثة أو الرسائل الخام إلى واجهة الذاكرة. أرسل خلاصة تفضيلات وحقائق مهمة فقط.
- مزود الذكاء الاصطناعي الأساسي والاحتياطي (New API وQwen/Ollama) يضبطان في التطبيق، وليس في الإضافة.

المصادقة المشتركة
- Header: X-SA-API-Key: <المفتاح الذي يولده مدير المتجر من إعدادات واتساب>
- استخدم HTTPS فقط.
- جميع المسارات تشترط تفعيل واتساب وخدمة العملاء، إضافة إلى تفعيل تكامل AutoMate من إعدادات الإضافة.
- Base URL: https://www.777736225.com/wp-json/smart-advisor/v1/whatsapp/assistant

1) GET /capabilities
يعيد قدرات التكامل، وما إذا كانت الذاكرة والمعرفة مفعّلتين، ويؤكد أن المحادثة الحية لا تحفظ في الإضافة.

2) POST /knowledge
مثال طلب:
{
  "intent": "product_search",
  "query": "عطر رجالي",
  "limit": 5,
  "sender": "اسم أو رقم المرسل",
  "phone": "9677XXXXXXXX"
}

النيات المدعومة:
- product_search: بحث WooCommerce، ويتطلب تفعيل مهارة البحث.
- product_details: تفاصيل منتج أو بحث باسمه.
- offers: المنتجات المتاحة للبيع وعليها خصم، ويتطلب تفعيل مهارة العروض.
- store_info / store_location / shipping_policy / returns_policy / general: حقائق المتجر المسجلة في إعدادات خدمة العملاء.

الاستجابة تشمل facts وproducts وhas_verified_data. الأسعار والروابط والمخزون مصدرها WooCommerce. لا تخترع بيانات إذا لم تتوفر.

3) POST /account-action
عمليات الحساب الحساسة فقط، ولا يعيد هذا المسار نص محادثة نهائياً.
- تسجيل: { "action": "register", "phone": "9677XXXXXXXX", "sender": "..." }
- رابط دخول: { "action": "magic_login", "phone": "9677XXXXXXXX", "sender": "..." }
يعيد status منظماً مثل account_created أو account_exists أو link_created، ومع رابط مؤقت عند الحاجة. لا تسجل الرابط أو الرمز في السجلات. صلاحية رابط الدخول 600 ثانية ويستخدم مرة واحدة؛ رابط إعداد الحساب 24 ساعة.

4) POST /memory
كل العمليات ترسل sender أو phone، ويُفضّل إرسال phone بصيغة دولية عند توفره.

استرجاع:
{ "action": "get", "sender": "...", "phone": "9677XXXXXXXX" }

حفظ خلاصة فقط:
{
  "action": "save",
  "sender": "...",
  "phone": "9677XXXXXXXX",
  "event_id": "uuid-unique-event",
  "revision": 12,
  "memory": {
    "summary": "خلاصة قصيرة للحقائق الدائمة التي تفيد خدمة العميل",
    "preferences": { "preferred_product_type": "عطور رجالية" },
    "interests": ["العطور"],
    "constraints": ["ميزانية محدودة"],
    "confirmed": false
  }
}

الحقول المقبولة داخل memory فقط: summary, preferences, interests, constraints, confirmed.
لا ترسل history أو messages أو transcript. الحد الأقصى لحجم الذاكرة 6000 بايت. confirmed=false هو الافتراضي؛ لا تعتبر الاستنتاجات غير المؤكدة حقائق مؤكدة.

حذف خلاصة AutoMate المحفوظة فقط:
{ "action": "delete", "sender": "...", "phone": "9677XXXXXXXX" }
هذا لا يسحب موافقة العميل ولا يحذف ملفه ومشاريعه. يمكن تنفيذ حذف خلاصة AutoMate حتى بعد سحب الموافقة، بشرط نجاح مصادقة API والتحقق من هوية العميل. أما حذف ملف العميل ومشاريعه والبيانات الأخرى فيبقى عبر مسار الخصوصية الحالي في الإضافة.

حماية التزامن:
- event_id يمنع تطبيق الحدث نفسه مرتين.
- revision يمنع استبدال ذاكرة أحدث بتحديث أقدم.
- عند 409 stale_revision، استرجع الذاكرة الحالية وادمج محلياً ثم أعد المحاولة بمعرف حدث جديد.
- عند انقطاع الاتصال، احتفظ بخلاصة التحديث في outbox محلي مشفر وأعد المحاولة لاحقاً.

الخصوصية:
- لا تخزن أي خلاصة قبل تحقق موافقة العميل من SA_Customer_Behavior.
- إذا consent_required=true فلا تحفظ ولا ترفع الذاكرة.
- لا ترفع تفاصيل محادثة، أو بيانات دفع، أو كلمات مرور، أو رموز دخول.
- لا تخلط ذاكرة محادثة مجموعة مع ملف فرد. لا تحفظ ذاكرة عميل من مجموعة إلا بعد هوية فردية موثوقة.

التوافق المرحلي
- /whatsapp/reply القديم يبقى موجوداً للتوافق مع الإصدارات السابقة.
- في تكامل AutoMate الجديد، لا تستخدم /whatsapp/reply للردود الحوارية العادية؛ استخدم /assistant/knowledge و/assistant/memory و/assistant/account-action، وصغ الرد في التطبيق.
- عمليات التسجيل ورابط الدخول السحري تبقى عمليات حساب حساسة داخل الإضافة، ولا تعِد إنشاء منطق التوكن في التطبيق.
