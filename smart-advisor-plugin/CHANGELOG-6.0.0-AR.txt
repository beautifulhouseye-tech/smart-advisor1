Smart Advisor 6.0.0 — المهارات الإضافية للمساعد

الإضافات:
- مهارة اكتشاف المنتجات المكملة: تستخدم WooCommerce cross-sells وupsells، ثم المنتجات المنشورة والمتاحة من التصنيفات المشتركة عند الحاجة.
- مهارة متابعة احتياجات المشاريع: تعرض المشاريع النشطة المملوكة للعميل والاحتياجات المسجلة غير المكتملة فقط، مع احترام موافقة حفظ بيانات العميل.
- مهارة العروض والخصومات: تعرض المنتجات المنشورة ذات التخفيض الفعلي في WooCommerce وتحسب مقدار ونسبة الخصم من السعرين الفعليين.
- إضافة مفاتيح تشغيل مستقلة للمهارات الثلاث في إعدادات خدمة العملاء.
- إضافة نقاط REST API محمية بمصادقة العميل، ومحددة بعدد الطلبات، وتتحقق من تفعيل المهارة على الخادم.

نقاط API:
- POST /wp-json/smart-advisor/v1/skills/complementary-products  {"product_id": 123, "limit": 4}
- GET  /wp-json/smart-advisor/v1/skills/project-followups
- GET  /wp-json/smart-advisor/v1/skills/project-followups?project_id=123
- GET  /wp-json/smart-advisor/v1/skills/offers?limit=8&max_price=100

الأمان والحدود:
- جميع النقاط تتطلب مصادقة العميل عبر SA_Customer_Profile.
- يتم رفض الاستخدام إذا كانت المهارة أو إعدادات خدمة العملاء معطلة.
- متابعة المشاريع محصورة بمشاريع المستخدم الحالي وتتطلب موافقته على حفظ بيانات المستشار.
- لا يتم تعديل الطلبات أو السلة أو إصدار كوبونات.
- لا يتم اختراع عروض؛ المصدر هو أسعار التخفيض المنشورة فعلياً في WooCommerce.
- لا تدخل مشتريات العميل الشخصية في المشاريع تلقائياً.

ملاحظة التكامل:
- تمت إضافة خدمات REST الخلفية. يلزم أن تستدعي واجهة المحادثة/العميل هذه النقاط لعرضها كتجربة محادثة تلقائية؛ تفعيل المهارة وحده لا يضيف أزراراً أو تدفق واجهة تلقائياً.
